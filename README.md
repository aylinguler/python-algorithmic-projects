# 🧠 Python Algorithmic Projects

This repository contains Python implementations focused on **algorithmic thinking, logical problem solving, and structured programming**.  
The projects explore topics such as recursion, number theory, object-oriented design, and algorithm development.

---

## 📌 Included Projects

### 💰 Budget App – Spending Tracker and Visualizer

This project implements a simple budgeting system in Python.  
It allows users to manage **deposits, withdrawals, and transfers between budget categories** while maintaining a ledger of transactions.

Additionally, the program generates a **vertical bar chart** that visualizes the percentage of total spending across categories.

**Key Concepts**
- Object-Oriented Programming (OOP)
- Lists and dictionaries for transaction storage
- String formatting and alignment
- Basic data visualization using ASCII charts
- Modular Python design

---

### 🧩 Sudoku Solver (Backtracking Algorithm)

Developed an object-oriented Sudoku solver in Python using **recursive backtracking** and constraint validation to solve standard **9×9 puzzles**.  
The program systematically tests possible number placements while enforcing Sudoku rules for rows, columns, and 3×3 subgrids.

**Key Concepts**
- Recursion
- Backtracking
- 2D matrix manipulation
- Algorithm design
- Object-oriented programming

---

### 🕒 Time Calculator

A Python program that calculates time durations by adding a given duration to a starting time, correctly handling **AM/PM changes and day transitions**.

**Key Concepts**
- Modular arithmetic
- Conditional logic
- String parsing

---

### 🔢 Right Truncatable Numbers

Generates and validates **right truncatable prime numbers**, where removing digits from the right side of the number always produces another prime number.

**Key Concepts**
- Prime number checking
- Iterative truncation
- Basic number theory
